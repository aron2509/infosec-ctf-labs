# Лабораторная 01: SSH Backdoor через authorized_keys

## 📚 Описание

CTF-задание: студент должен найти скрытые SSH-бэкдоры в системе Parrot OS и доказать, кто их вставил.

## 🛠️ Подготовка

1. Зайти в виртуалку ученика
2. Выполнить от sudo:
```bash
sudo ./01-ssh-backdoor/scripts/setup_ctf_env.sh
```

## ⏱️ Тайминг
- Время на выполнение: 60 минут
- Кол-во флагов: 7

## 📄 Студенты получают
- Файл `/student_template/report_template.txt`
- Доступ к системе
- Таймер

- Нельзя удалять файлы
- Использовать только стандартные утилиты
