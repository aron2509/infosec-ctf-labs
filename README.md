
# 🧠 Лаборатория: Обнаружение SSH-бэкдора

---

## 📚 Описание

На вашей машине обнаружены признаки несанкционированного доступа.  
Ваша задача — провести расследование и определить:

- Кто мог оставить себе доступ
- Где именно он сохранил точку входа
- Какую команду он использовал для изменения системы
- Какие артефакты остались после атаки

Вы должны **найти два бэкдора**, зафиксировать все следы и **представить отчёт**.

---

## 🛠️ Установка среды

Перед началом необходимо запустить установку окружения CTF:

```bash
sudo ./install_ctf.sh
```

После завершения появится сообщение `✅ Готово. Среда развернута.`

⚠️ **Не пытайтесь редактировать, просматривать или модифицировать файл установки.**  
Работайте как цифровой следователь: ищите следы, а не исходники.

## 📌 Что нужно найти (ваши флаги):

1. Сколько пользователей имеют файл `authorized_keys`?
2. Имя пользователя, который не является системным (внедрён вручную)
3. Первые 20 символов ключа из `authorized_keys` пользователя `student`
4. Первые 20 символов ключа из `authorized_keys` внедрённого пользователя
5. Дата создания файла `.ssh/authorized_keys` у этого пользователя
6. Какая команда модифицировала файл у `student`?
7. Какая команда модифицировала файл у скрытого пользователя?

---

## 🧠 Подсказки

- Используйте команды:
  - `find`
  - `ls -l`
  - `stat`
  - `sudo ausearch -k ...`
- Изучайте системные логи: `journalctl`, `auth.log`, `auditd`

Не забывайте проверять:
- Кто изменил файл (UID)
- Как (через `bash`, `nano`, `tee` и т.д.)
- Когда
- Где именно
